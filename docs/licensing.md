# Licensing and provenance

Every source and image retains its URL, institution, attribution, record hash, and rights fields. Missing or ambiguous image rights mean **no redistribution**: the source reference is stored as restricted, the bytes are not copied to R2, and a review record is created.

CC0 and public-domain claims are accepted only from explicit source metadata. Institution credit is preserved even when attribution is not legally required. Historical descriptions remain attributed source claims rather than being rewritten as verified facts.

`pnpm export` emits published records only when no related restricted image exists. It excludes credentials, private raw storage, and restricted media.

The MIT license covers repository software and documentation authored for Culturio. It does not relicense museum metadata, images, names, marks, or the depicted cultural heritage.
